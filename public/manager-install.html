Spielzeit Manager

Windows mit Microsoft Edge: Oben rechts auf ⋯ → Apps → Diese Website als App installieren klicken. Das Manager-Icon mit M erscheint danach im Startmenü und kann an die Taskleiste geheftet werden.

iPhone/iPad mit Safari: „Manager jetzt öffnen“, dann Teilen → Zum Home-Bildschirm.

Das Manager-Icon ist eigenständig und führt direkt zu „Video & Analyse“. Das normale SpielzeitApp-Icon bleibt für die Spieler- und Elternansicht erhalten.

Du verwendest deinen bestehenden SpielzeitApp-Login. Beim ersten Öffnen des neuen Icons kann eine Anmeldung nötig sein.
