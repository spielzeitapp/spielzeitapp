# Tournament base lineup and preparation readiness

A staff-only tournament template stores formation, start block and complete Block A/B before any match exists. Incomplete drafts remain editable. Readiness requires both blocks complete, distinct active nominees per position, same playing format, no injured starter and an unchanged full tournament squad. Actual attendance, squad, own plan and saved lineup facts drive the preparation checklist; live play and completion remain separate.

The trainer explicitly applies a saved template to an empty upcoming own match. The transaction checks the template revision, current event and season, staff permissions, own match relationship, status, existing lineup/events and incompatible bench. It atomically saves starters, bench, formation and both block plans. A repeat never overwrites an existing lineup. Adopted plans load on another staff device; normal match variant storage retains existing behavior. Remote updates use existing match staff policies. Public match DTOs remain unchanged.
